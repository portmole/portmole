# portmole

Expose a local port to the internet from your coding agent.

```
npx -y portmole mcp          # as an MCP server, for Claude Code, Codex, Cursor
npm install -g portmole      # or as a command
portmole http 3000
```

This package installs the portmole program for your platform (Windows, macOS
or Linux, x64 or arm64). Documentation and source:
https://github.com/portmole/portmole
